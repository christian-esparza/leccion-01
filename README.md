# Lección 01: Mi Primer Script en Python

Este repositorio contiene un programa en Python interactivo ejecutado en un entorno de desarrollo con Ubuntu sobre WSL.

## Archivos
- `hola.py`: Solicita el nombre y el año de nacimiento del usuario, calcula su edad aproximada y evalúa mediante estructuras condicionales (`if/else`) si es mayor o menor de edad.

## Ejecución
```bash
python3 hola.py
```
