# Lección 01: Mi Primer Script en Python

Este repositorio contiene un programa en Python interactivo ejecutado en un entorno de desarrollo con Ubuntu sobre WSL.

## Archivos
- `hola.py`: Solicita el nombre y el año de nacimiento del usuario, calcula su edad aproximada y muestra un saludo personalizado en la consola.

## Ejecución
```bash
python3 hola.py
```
